## Problem Understanding
**What the problem is asking:** 
The Problem asks us to primarily **manage the cargo system** by substituting as many of it's failed systems as possible , which includes an **approval** check to keep the weight under limit along with several other functions such as finding out the **average weight, sorting the shipments ,searching containers** and many more , all done using **weight as a primary identifying factor** .

**Key concepts involved:** 
- User Input-Output
- Looped Switch Case
- Arithmetic Operations in Arrayed Data
- Sorting of Array
- Binary/Linear search in Array

**My approach:** 
 - The entire functional implementation is divided into segments using a looped switch case , which keeps on running on the data set provided allowing the user to perform multiple functions before exiting the program .
 - The input array is pre-sorted ,ie sorted before the user prompts to do so to better allow functional applications .
 - Using Bubble Sort for sorting and Binary Search for searching , in order to optimise time and memory allocated under the given guidelines .
